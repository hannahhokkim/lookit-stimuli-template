# SWARM baseline videos

These four baseline videos show the existing test reveal displays without a preceding goal-action demonstration. They preserve the goal objects, background, and final agent arrangements from the v18 test materials. There is no same-goal/different-goals manipulation in these baselines.

The half-number displays contain either one group of 8 agents or two groups of 8 (16 total). The full-number displays contain one group of 16 or two groups of 16 (32 total). The one-group displays preserve the yellow agent identity used in the existing test videos.

Each video is 55 seconds: a 2-second covered scene, the original 3-second attention/reveal segment, then a 50-second static hold of the revealed display. The reveal becomes visible during the transition; 5 seconds marks the start of the fully settled display, not the first frame in which agents are visible. For precise looking-time coding, identify full visibility frame-by-frame. These videos alone do not enforce parent-controlled trial stopping.

Audio comes from the corresponding original reveal segment and final background music. The source music ends at output time 53 seconds; the final 2 seconds are silent. No action demonstration audio is added.

This implements the no-action baseline logic of Brody et al. using SWARM group stimuli, rather than reproducing the paper's individual-agent stimuli. Publishing these files does not install the revised protocol in the live Lookit study. The manifest records the source and timing for each clip. The checksheets show frames across each exported video.
